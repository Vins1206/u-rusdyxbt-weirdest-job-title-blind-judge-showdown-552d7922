# Weirdest Job Title: Blind Judge Showdown

Entry for the [Weirdest Job Title: Blind Judge Showdown](https://make.fun/c/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) bounty on make.fun ($5, top 10).

## What it does

`main.py` writes a single job title — the weirdest one we could think of — to `/output/entry.txt`, and nothing else:

> Full-Time Apologizer to Angry Geese

35 characters. A real-sounding job title (full-time apologizer) with one hilariously specific twist (the clients are angry geese) — instantly pictured, instantly funny.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

Pure Python standard library, no dependencies. Deterministic: every run writes the exact same bytes.
